NO GODS AHEAD

---QUICK INFO ABOUT THE GAME---
No gods ahead is a 3D FPS Game that takes place in post-apocalyptic poland after an explosion of a bomb that destroyed time.
You play as a solider trapped in enemies base, you survive the explosion without even knowing it ever happened.
After you escape your enemies base, you realise what happened.
You travel through destroyed poland and discover the bomb disrupted space-time, in some places stopping it at the moment of explosion, in some places returning it to the time before the explosion, and in some places after the explosion.
As the player learn different mechanics that they can use in different parts of the country the solve the mystery about the bomb explosion.

--- TECHNICAL INFO ---
Game is created in Unreal Engine 4.27.2 Using C++ and Blueprints.
There is one Game Designer and one Game Developer.
About 10 people test the game after major updates and leave the review of what needs a change.
All assets are created by Game Designer in Blender / Unreal Engine.
The campaign was written by both Game Designer and Developer.
This project was created to learn C++ in UE and Game Design.
This project will be used in both creators portfolios as an example of our work and abilities.
